Samman design system

This page defines the semantic CSS tokens and component classes for sammancoaching.org. Every component on it is built only from these tokens, so switching the theme above shows how each one looks in dark mode.

  1. Components use semantic tokens, never brand colours. Write var(--color-text), not $dark-blue. The brand palette appears in exactly one place, the token definitions, which is what makes dark mode a token swap.
  2. One class per concept. There is one button (.btn), one bordered box (.panel), one avatar (.avatar). Variants are modifiers (.btn--sm), not new components.
  3. BEM naming. .block, .block__element, .block--modifier, matching what the site already does for coach-row and member-hero.
  4. States are is-* classes. .is-current, .is-active, .is-success, .is-error. JavaScript toggles these and nothing else.
  5. No colour or spacing literals in components. If a value is missing, add a token here first.

Dark mode follows the visitor's OS setting. Setting data-theme="light" or data-theme="dark" on <html> overrides it, which leaves room for a site-wide toggle later.

Deliberate visual changes

  • Blockquote text uses --color-text-muted instead of the grey #6a737d.
  • Muted text uses a colour token instead of opacity, so links inside it keep their colour.
  • Radii are rounded to three values: the header and nav go from 5px to 6px and the date badge from 8px to 10px.
  • The code copy button's success and error icons use currentColor instead of hardcoded colours.

Open decisions

These colour pairs fail WCAG AA contrast (4.5:1 for body text) today. Each one is a single token, so fixing it is a one-line change.

PairWhereContrastSuggestion
Light blue on white--color-action-text: every .btn label (light mode)1.8:1Use dark blue (10.7:1) and keep the light blue border.
Off-white on coral--color-on-brand: navigation links2.2:1Use dark blue (4.2:1). Bold text at 18.7px or larger would then pass.
Coral on off-white--color-link-hover (light mode)2.2:1Hover state only, so lower priority. An underline on hover would help.

In dark mode, light blue on navy is 7:1 and coral on navy is 5:1, so these pairs pass there.
