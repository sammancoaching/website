{%- comment -%} A button that copies a block of markdown to the clipboard, for people who want to paste the requirements into a coding agent without losing formatting. Usage in a page: {% capture my_section %} ## Some heading ...markdown... {% endcapture %} {{ my_section }} {% include copy_markdown_button.html markdown=my_section %} The copied text is prefixed with the page title as a level-1 heading. Behaviour lives in assets/js/copy_markdown.js, styling in _sass/_copy_markdown.scss. {%- endcomment -%}
